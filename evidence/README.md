# Submission evidence

[EVIDENCE.md](../EVIDENCE.md) indexes the screenshots, command output, and outstanding submission evidence. Screenshots and transcripts show their capture-time state; use their dates when comparing test counts and deployment revisions. The root [README](../README.md) contains the project documentation and module checklist.

Keep passwords, tokens, sign-in prompts, Terraform state, and Secret values out of evidence. Public resource/account identifiers are configuration, not credentials.
